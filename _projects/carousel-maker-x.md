Give the app a topic and a locally running Qwen3 model drafts a five-slide sequence. Each title and body can be edited in the browser before exporting individual SVG slides.

This is a local-only experiment. It needs Ollama and a downloaded Qwen3 model, so there is no public browser demo yet. It does not generate images.
